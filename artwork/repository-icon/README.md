open_router_cli's icon: an Icon Composer document (OpenRouterCLI.icon: a
glass terminal prompt on indigo). Rendered to .github/icon.png, where Reviews and other tools look for a
repository's icon:

    ictool artwork/repository-icon/OpenRouterCLI.icon --export-image --output-file .github/icon.png \
        --platform iOS --rendition Default --width 512 --height 512 --scale 1

(`ictool` is in Xcode's Icon Composer.app, Contents/Executables.)
